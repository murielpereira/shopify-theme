## 2024-05-18 - Optimized Liquid loop performance using native contains check and inline capture
**Learning:** In Shopify Liquid, looping through arrays multiple times (e.g. iterating over `product.tags` to find a specific tag, or iterating over `item.properties` once to check and once to render) introduces significant rendering overhead. Using the native `contains` operator evaluates the check natively at the C/Rust level, effectively turning an O(N) evaluation per page render into an O(1) operation. For rendering elements conditionally based on item properties, capturing the HTML output inside the loop reduces the number of loops needed.
**Action:** When evaluating if an array contains a specific string in Shopify Liquid, prefer the native `contains` operator instead of manual `{% for %}` loops. Additionally, avoid looping over arrays twice to conditionally render. Opt for single-pass iterations using `{% capture %}` or string append techniques to minimize Liquid processing overhead.
